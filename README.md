# Domus Virtual Tours

Lovable Prompt — Domus Property Media Website

Build a website for Domus Property Media, a Budapest-based company that creates 360° virtual tours for real estate (especially Airbnb/short-term rentals) and small businesses (cafés, shops). The tours get embedded on Google Maps and client websites.

Brand identity

Name: Domus Property Media

Domain: domuspm.com

Style: premium, clean, restrained — confident and understated, never "salesy" or loud. No flashy animations, no clutter. Think boutique real estate / architecture studio, not a generic SaaS landing page.

Colors:

Dark navy (primary background/brand color) — approx #16283F

Gold/bronze (accent — buttons, links, highlights, dividers) — approx #C89B5C

Off-white/cream (light background, not pure white)

Optional pale greige for secondary backgrounds

Typography:

Headlines: bold geometric sans-serif (Montserrat, Poppins, or similar)

Small labels/eyebrow text: letter-spaced, thin uppercase (mirrors the "PROPERTY MEDIA" subtitle style in the logo)

Body text: clean, readable sans-serif (Inter or similar)

Motif: a thin-line arched doorway shape (from the logo) — usable as a subtle recurring divider or section accent, used sparingly

Logo: dark navy circle badge with gold ring border, gold arch icon, "DOMUS" in bold white, "PROPERTY MEDIA" in gold small caps below it (I will upload the logo file separately)

Language

Bilingual site: Hungarian (default) and English, with a language toggle in the header. Keep all copy short and easy to translate — avoid idiomatic phrases that are hard to localize.

Site structure / sections

Hero (Homepage top)

Short, confident headline + subheadline promising the core value (e.g. "360° Virtual Tours for Homes & Businesses" / "See it before you book it.")

Primary CTA button: "Get a Quote" / "Kérj ajánlatot"

Background: a still frame or short looping clip suggestion from a 360° tour (placeholder for now)

Featured tours

2–3 embedded/linked 360° virtual tours displayed prominently (placeholder embeds for now — I'll provide real links)

Each with a small caption: property/business name + type

Services

Two clear tracks with separate messaging:

Real estate / Airbnb hosts — faster bookings, higher trust, stand out on listings

Small businesses / cafés — get discoverable and stand out on Google Maps

Keep each block short: 1 headline + 2-3 lines + small icon

Pricing

Simple 3-tier pricing table:

19,990 HUF — up to 60 m²

29,990 HUF — up to 120 m²

Custom quote — above 120 m² ("Contact us" / "Kérj egyedi ajánlatot")

Highlight: 48-hour turnaround, shown as a trust badge near the pricing table

Portfolio / Tours gallery

Grid/gallery layout for finished project tours, expandable over time

Should look clean even with only 1-2 items right now (design for growth)

About

Short section (2-3 sentences): local Budapest team, fast turnaround, premium quality — no heavy "corporate" backstory, since this is a new sole proprietorship

Testimonials / Social proof

Simple space for 1-2 client quotes (starting with the café reference), designed to scale as more come in

Contact / Booking

Simple contact form (name, email, property/business type, message) or a booking-calendar style component

Plus direct email/phone display

Footer

Logo, short tagline, social links (Instagram, Facebook), contact email, language toggle repeated

Functional requirements

Fully responsive, mobile-first (most traffic will likely be mobile via Instagram/Facebook links)

Fast-loading, minimal animation — subtle fade-ins only, nothing distracting from the tour embeds

Clear, single primary CTA repeated at top and bottom of the page ("Get a Quote")

Placeholder-friendly: make it easy to swap in real tour embeds, photos, and testimonials as they come in

Tone of copy

Write all placeholder copy in a premium-but-approachable, fact-based tone (e.g. lead with the 48-hour turnaround and quality, not hype or exclamation marks). Keep sentences short.
